#RegEx Exercises

The RegEx folder contains 10 Python programs:

1. Match `a` followed by zero or more `b`
2. Match `a` followed by two or three `b`
3. Find lowercase words joined by underscore
4. Find uppercase letters followed by lowercase letters
5. Match strings starting with `a` and ending with `b`
6. Replace spaces, commas, and dots with colons
7. Convert snake case to camel case
8. Split strings at uppercase letters
9. Insert spaces between capitalized words
10. Convert camel case to snake case

#Receipt Parser

The receipt_parser.py program reads raw.txt and extracts:

- Product names
- Prices
- Total amount
- Date
- Time
- Payment method

The result is displayed in JSON format.
